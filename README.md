 - 1. Общее описание системы
      
Система представляет собой веб-приложение, предназначенное для отображения актуальной информации о занятости аудиторий учебного корпуса в режиме реального времени. Основные пользователи — студенты и преподаватели университета

Основные сущности:
Пользователь — студент или преподаватель, прошедший регистрацию.

Аудитория — помещение в учебном корпусе, имеющее номер, этаж, координаты на плане, вместимость и оснащение.

Этаж — уровень здания, содержащий план и набор аудиторий.

Занятие — запись в расписании: аудитория, день недели, время начала и окончания, предмет, преподаватель, группа.

Статус аудитории — текущее состояние: «свободна», «занята», «перемена», «нет данных».

2. Роли пользователей
   
   
Гость -	Неавторизованный пользователь	Просмотр карты, статусов аудиторий, фильтрация, поиск

Студент	- Авторизованный пользователь с указанной группой	Всё, что гость + привязка к своей группе, персональные уведомления

Преподаватель -	Авторизованный пользователь с ролью преподавателя	Всё, что студент + ручная отметка занятости аудитории

Администратор	- Сотрудник, отвечающий за данные	Управление расписанием, аудиториями, пользователями
